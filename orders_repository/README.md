## Repository Structure

```
orders_repository/
├── 01_appointments_and_transfers/     # 169 Transfer orders & 38 PSC appointment notifications
├── 02_service_confirmation/           # 83 Service confirmation orders in WBAH&VS
├── 03_mcas_and_promotions/            # 75 MCAS promotion orders (8, 15, 16, 24, 25 years)
├── 04_cadre_restructuring_and_rules/  # Landmark Rules No. 1808, Schedule No. 1809, HoO No. 575
├── 05_gradation_lists_and_rosters/    # Final Gradation List No. 3768 & 50-Point Roster
├── 06_general_orders_and_circulars/   # 49 Misc orders, leave rules, SAR/APR hierarchies
├── orders_master_index.csv            # Tabular master index with metadata and links
└── orders_master_index.json           # Machine-readable JSON index for LLM ingestion
```
